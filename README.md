# 🎙️ Gagan Voice Assistant – AI Powered Desktop Assistant

**Gagan Voice Assistant** is a simple yet powerful desktop voice assistant made using Python. It can listen to your voice, respond intelligently, and help you perform common tasks hands-free like playing music, searching Google, checking time, telling jokes, and more.

---

🧠 Features

- 🎤 Wake word detection: “Hey Gagan”
- 👂 Manual Start Listening button
- 🔊 Offline Text-to-Speech (TTS) response
- 📺 Play any song from YouTube
- 🧠 Get answers from Wikipedia
- ⏱️ Tells you the current time
- 😂 Tells you jokes
- 🌐 Web search on any topic
- 🧼 Clean, soothing, animated UI using `customtkinter`

---

💻 Tech Stack

- Python 3.11+
- customtkinter
- speech_recognition
- pyttsx3
- pywhatkit
- wikipedia
- pyjokes
